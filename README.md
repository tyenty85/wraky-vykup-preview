# WRAKY.COM — veřejný náhled

Statická ukázka kalkulátoru výkupu vozidel. Otevřete `index.html` nebo nasaďte celý adresář na statický hosting.

## Katalog vozidel

Výběr značek, modelů a motorizací vychází z projektu [Vehicle Makes and Models](https://github.com/gor3a/vehicle-makes-models), jehož datová fakta pocházejí z [Autoevolution](https://autoevolution.com/). Data byla převedena pro nabídky WRAKY.COM a jsou dostupná v `vehicle-catalog.json`.

Databáze a upravená verze jsou pod [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Kód projektu je samostatný. Viz také `LICENSE-DATA` upstream projektu.

## Poznámka k ukázce

Formulář orientačně počítá cenu v prohlížeči. Odeslání e-mailu, generování PDF na serveru a dekódování VIN zatím vyžadují navazující serverovou službu.
